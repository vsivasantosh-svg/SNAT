Brand-New Laptop
Unboxing & Setup Guide

A practical step-by-step checklist to inspect your new laptop, configure Windows, verify hardware, improve security and get your device ready for everyday work.

Prepared by SNAT Siva Santosh

Use this guide before loading the laptop with personal files or installing lots of software. Complete the checks in order and keep your invoice, warranty details and recovery information safe.

1. Unbox and inspect the laptop

Check the packaging

Look for dents, tears, broken seals or signs of mishandling. Take photos or a short unboxing video.

Inspect the hardware

Check the display, keyboard, touchpad, hinges, webcam, speakers, charger and all ports.

  • Confirm the exact model, serial number and included accessories.
  • Check the invoice, warranty duration and manufacturer support registration.
  • Do not throw away the packaging until the laptop passes inspection.

2. Complete the first Windows setup

Connect the original charger if needed, power on and follow the Windows first-run setup.

  1. Select your country/region and keyboard layout.
  2. Connect to a trusted Wi-Fi network.
  3. Sign in with the intended Microsoft account or configure an available local-account option.
  4. Set a strong sign-in method, such as Windows Hello PIN.
  5. Review privacy choices instead of accepting every optional setting automatically.
  6. Confirm date, time and time zone. For India, use India Standard Time (UTC+05:30).

Essential First Setup: 5 Windows Settings

Before installing your applications, review these settings to improve startup speed, device security, updates and recovery.

01 • Startup

Disable unnecessary Startup apps

Press Win + I → Apps → Startup. Turn off apps you do not need at sign-in, such as Spotify, Teams (if not required), game launchers or other non-essential apps.

Keep Windows Security enabled. Only disable apps you recognize and are sure you don't need at startup.

02 • Device location

Turn on Find my device

Press Win + I → Privacy & security → Find my device. Turn it on, and make sure location services are enabled if Windows asks.

When supported and configured, this can help you locate your device or see its last known location if it is lost. It generally requires a Microsoft account and internet connectivity.

03 • Antivirus trial

Remove unwanted trial antivirus

If a third-party antivirus trial is preinstalled and you don't intend to use it, uninstall it from Settings → Apps → Installed apps.

Windows Security / Microsoft Defender Antivirus should provide protection when no other compatible antivirus is active. Open Windows Security and verify protection is on after uninstalling.

04 • Updates

Install updates and optional drivers

Settings → Windows Update → Check for updates. Also review Advanced options → Optional updates → Driver updates.

Install relevant drivers for your laptop. Prefer the manufacturer's official support page for model-specific drivers and BIOS updates.

05 • Recovery

Enable System Protection

Search Windows for Create a restore point. Select the Windows system drive → Configure → Turn on system protection → Apply.

Choose Create and name the restore point (for example, Fresh Laptop Setup). Restore points can help undo certain system changes, drivers or software installations—but they are not a replacement for personal-file backups.

Quick summary

  1. Startup apps: Disable unnecessary apps.
  2. Find my device: Turn on.
  3. Antivirus trial: Uninstall if unwanted; verify Windows Security protection.
  4. Updates: Install Windows updates and review optional driver updates.
  5. Restore point: Turn on System Protection and create an initial restore point.

3. Run these essential Windows checks

System details

System Information

Press Win + R, type msinfo32. Review processor, RAM, BIOS and system model.

Device health

Device Manager

Press Win + X → Device Manager. Look for warning symbols or unknown devices.

Storage

Disk Management

Press Win + R, type diskmgmt.msc. Confirm the installed drive and partitions.

Windows version

Version and activation

Run winver. Then check Settings → System → Activation.

Useful diagnostic commands

powercfg /batteryreport

Creates a battery report showing design capacity and current full-charge capacity. Open the HTML report path printed by Windows.

ipconfig /all

Displays network adapter and IP configuration.

dxdiag

Opens DirectX Diagnostic Tool for graphics and audio information.

sfc /scannow

Checks protected Windows system files. Run Terminal or Command Prompt as administrator.

4. Update Windows and manufacturer drivers

  1. Open Settings → Windows Update → Check for updates. Restart when requested and repeat until fully updated.
  2. Check the laptop manufacturer's official support page using the exact model or serial number.
  3. Install recommended chipset, graphics, Wi-Fi, Bluetooth, audio and touchpad drivers.
  4. Use the manufacturer's official utility for firmware or BIOS updates when needed.

Important: Keep the laptop connected to reliable power during a BIOS update. Do not interrupt the process. Avoid unofficial driver-updater tools.

5. Security and backup essentials

Protect the device

Keep Microsoft Defender, Windows Firewall and SmartScreen enabled. Use strong unique passwords and MFA.

Plan recovery and backup

Back up important files. If BitLocker/device encryption is enabled, securely save its recovery key away from the laptop.

  • Check Settings → Privacy & security → Windows Security.
  • Review Device Encryption or BitLocker availability and status.
  • Keep recovery keys private; never share them in messages or screenshots.
  • Set up a backup location, such as an external drive or trusted cloud service.

6. Useful software to consider

  • 7-Zip: file compression and extraction.
  • VLC: media playback.
  • Microsoft PowerToys: useful Windows productivity utilities.
  • Everything: fast local file search.
  • CrystalDiskInfo: drive health information.
  • Only install what you need. Download applications from their official websites or trusted stores.

7. Performance and everyday-use tips

  • Review Task Manager → Startup apps and disable only applications you recognise and do not need at startup.
  • Keep reasonable free space on the system drive.
  • Use Windows Storage settings to review temporary files before deleting anything.
  • Keep ventilation openings clear; use the laptop on a hard, flat surface.
  • Use the supplied charger and follow the manufacturer's battery-care guidance.
  • Clean the screen with a suitable microfiber cloth; do not spray liquid directly onto it.

8. Five essential Windows settings after unboxing

Open Windows Settings with Win + I. Review these settings before you start using the laptop regularly.

01 • Startup apps

Disable unnecessary startup applications

Path: Settings → Apps → Startup

  • Review apps such as Spotify, game launchers and Microsoft Teams.
  • Turn off apps you do not need immediately after signing in.
  • Disable OneDrive startup only if you do not rely on automatic file syncing.
  • Leave Windows Security notifications and essential security or hardware services enabled.

Benefit: Fewer background apps can reduce startup load and help Windows become ready sooner.

02 • Device location

Enable Find my device

Path: Settings → Privacy & security → Find my device

  • Turn on Find my device.
  • Enable Location services under Settings → Privacy & security → Location.
  • Sign in with a Microsoft account that supports this feature.

Benefit: If the laptop is lost, you may be able to see its last reported location through your Microsoft account. Location reporting is not guaranteed to be live or continuous.

03 • Antivirus trial

Review preinstalled antivirus trial software

Path: Settings → Apps → Installed apps

  • Identify any third-party antivirus trial that came with the laptop.
  • If you do not plan to use it, uninstall it using its normal uninstaller.
  • Restart Windows and open Windows Security to verify protection status.

Important: Microsoft Defender Antivirus normally resumes when a third-party antivirus is removed. Confirm that Microsoft Defender Antivirus and Firewall are active. Do not remove manufacturer security utilities or other components unless you know what they do.

04 • Windows updates

Check Windows and optional driver updates

Path: Settings → Windows Update

  1. Select Check for updates and install applicable updates.
  2. Open Advanced options → Optional updates.
  3. Review available driver updates and install only those appropriate for your laptop.
  4. Restart if requested, then check again.

Tip: Optional updates are not all essential. Prefer the laptop manufacturer's official drivers when a specific driver or firmware update is needed.

05 • System recovery

Enable System Protection and create a restore point

Search: Create a restore point

  1. Open Create a restore point from Windows Search.
  2. Select the Windows system drive, usually C:, and click Configure.
  3. Choose Turn on system protection.
  4. Set a suitable maximum disk-space usage and select Apply.
  5. Click Create, give the restore point a name such as “New laptop – initial setup”, and confirm.

Benefit: If a driver, application or update causes a problem, System Restore may return Windows system files, settings, drivers and installed applications to an earlier state.

Important: System Restore is not a full system backup and does not replace backing up personal files. Create a restore point before major driver or software changes.

9. Five important Windows settings to configure

Press Win + I to open Windows Settings. Complete these five checks after the initial Windows setup.

01 • Startup apps

Disable unnecessary startup apps

Go to Settings → Apps → Startup. Turn off apps you do not need immediately after signing in, such as OneDrive, Teams, Spotify or a game launcher, if you do not use them at startup.

Why: Fewer startup apps can reduce sign-in load and help Windows start more smoothly. Keep security, touchpad, audio and essential manufacturer utilities enabled. If you use OneDrive sync or Teams daily, leave them on.

02 • Find my device

Enable Find my device

Go to Settings → Privacy & security → Find my device and switch it on, if available.

Why: If the laptop is lost, you may be able to see its last reported location through your Microsoft account device page. It generally requires a Microsoft account, location services and an internet connection; it is not guaranteed to provide a live location.

03 • Antivirus trial

Review pre-installed antivirus trial software

If the laptop includes a third-party antivirus trial that you do not intend to use, you can uninstall it from Settings → Apps → Installed apps.

Before uninstalling: Confirm Microsoft Defender Antivirus is active in Windows Security and that no work/school policy requires the third-party product. Do not leave the laptop without active antivirus protection. Restart after uninstalling if requested.

04 • Windows updates

Check Windows updates and optional driver updates

Go to Settings → Windows Update → Check for updates. Then open Advanced options → Optional updates and review available driver updates.

Install relevant drivers for your exact laptop model. Prefer the laptop manufacturer's support page for critical chipset, graphics, BIOS and firmware updates. Optional updates are not all mandatory; avoid installing a driver that is not intended for your hardware.

05 • System Restore

Enable System Protection and create a restore point

  1. Open Start and search for Create a restore point.
  2. In the System Protection tab, select the Windows system drive (usually C:) and choose Configure.
  3. Select Turn on system protection, set a reasonable disk-space limit and select Apply.
  4. Select Create, enter a name such as Fresh Laptop Setup, and create the restore point.

Why: System Restore can roll back certain system files, drivers, registry settings and installed programs after a problematic change. It does not replace a backup and is not a complete undo button for personal files. Restore points may be removed or unavailable, so keep separate backups of important data.
